# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, argue about the change and not the person, and accept that the
maintainer's decision on a review is final.

To report behaviour that breaks it, use GitHub's **Report content** on the comment or
issue concerned, or contact the maintainer through this repository's private
vulnerability reporting form on the Security tab. Reports are kept confidential.
